# Глава 11: Многоязычная Поддержка

## 11.1 Обзор

Протокол ориентирован на глобальное сообщество разработчиков, предоставляя документацию на 9 языках.

## 11.2 Поддерживаемые Языки

| Код Языка | Язык | Путь Директории | Роль |
|-----------|------|----------------|------|
| `en` | English | `docs/en/` | Базовый язык |
| `zh-CN` | Упрощённый китайский | `docs/zh-CN/` | Перевод |
| `zh-TW` | Традиционный китайский | `docs/zh-TW/` | Перевод |
| `ja` | Японский | `docs/ja/` | Перевод |
| `ko` | Корейский | `docs/ko/` | Перевод |
| `de` | Немецкий | `docs/de/` | Перевод |
| `fr` | Французский | `docs/fr/` | Перевод |
| `es` | Испанский | `docs/es/` | Перевод |

## 11.3 Структура Директорий

```
docs/{language_code}/
├── specification/
│   ├── draft/
│   │   └── specification.md
│   └── 2025-11-25/
│       └── specification.md
├── blueprint/
│   └── illustration/
├── community/
├── develop/
└── sdk/
```

## 11.4 Стратегия Базового Языка

- Английский (en) служит базовым языком
- Весь новый контент сначала пишется на английском
- Другие языковые версии переводятся с английского
- При обновлении базового языка аннотируется статус синхронизации

## 11.5 Принципы Перевода

1. Технические термины сохраняются на английском (Skill Descriptor, Well-Known URI)
2. Концептуальные описания выражаются на целевом языке
3. Комментарии в примерах кода переводятся
4. Структура документа соответствует базовому языку
5. Каждая переведённая версия аннотирует номер версии базового языка

## 11.6 Аннотация Статуса Синхронизации

```markdown
---
base_version: en/2025-11-25
sync_status: synced | outdated | in_progress
last_synced: 2025-11-25
---
```
