# Глава 2: Глоссарий

## 2.1 Основные Термины

| Термин | Английский | Определение |
|--------|-----------|------------|
| iFay | iFay | Интеллектуальная когнитивная система-партнёр. Основной потребитель Skill Sharing Protocol, обнаруживающий и вызывающий навыки для расширения собственных возможностей |
| Навык | Skill | Вызываемая единица возможности, объявленная в соответствии с протоколом. Включает плагины, API, пакеты знаний и возможности выполнения задач |
| Провайдер навыков | Skill Provider | Сущность (человек, организация или автоматизированная система), объявляющая и предоставляющая навыки в Интернете |
| Потребитель навыков | Skill Consumer | Сущность, обнаруживающая и вызывающая навыки. Преимущественно экземпляры iFay |
| Дескриптор навыка | Skill Descriptor | Документ метаданных навыка, определённый в соответствии со Schema протокола, описывающий возможности, интерфейсы, методы вызова и т.д. |

## 2.2 Термины Протокола

| Термин | Английский | Определение |
|--------|-----------|------------|
| Механизм обнаружения | Discovery Mechanism | Методы и процессы, с помощью которых потребители навыков находят и обнаруживают Skill Descriptors в децентрализованных сетях |
| Schema протокола | Protocol Schema | Формализованная спецификация, определяющая структуру Skill Descriptors. Включает JSON Schema, типы TypeScript и документацию MDX |
| Реестр навыков | Skill Registry | Опциональный сервис индексации навыков для ускорения обнаружения, но не обязательное условие работы протокола |
| Точка вызова | Invocation Endpoint | Адрес точки входа для удалённых вызовов, объявленный в Skill Descriptor |
| Тип возможности | Capability Type | Классификационный идентификатор навыка. Включает plugin, api, knowledge, task |
| Schema Validator | Schema Validator | Инструмент или компонент для валидации соответствия Skill Descriptors Schema протокола |
| Версия протокола | Protocol Version | Идентификатор версии спецификации протокола. Следует Semantic Versioning |

## 2.3 Технические Термины

| Термин | Английский | Определение |
|--------|-----------|------------|
| Well-Known URI | Well-Known URI | Стандартизированный путь обнаружения `/.well-known/skill-sharing`. Используется для предоставления индекса навыков под доменом |
| Индекс навыков | Skill Index | Документ, возвращаемый Well-Known URI. Содержит список ссылок на все объявленные Skill Descriptors под доменом |
| Семантическое версионирование | Semantic Versioning (SemVer) | Формат номера версии `MAJOR.MINOR.PATCH`. Используется для управления версиями протокола |
| JSON Schema | JSON Schema | Стандарт для описания структур данных JSON. Данный протокол использует Draft 2020-12 |
| Политика доступа | Access Policy | Уровень видимости навыка: публичный (public), ограниченный (restricted), приватный (private) |
| ID выполнения | Execution ID | Уникальный идентификатор, возвращаемый после вызова навыка. Используется для отслеживания статуса выполнения и получения результатов |
