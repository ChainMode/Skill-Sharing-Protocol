# 第二章：术语表

## 2.1 核心术语

| 术语 | 英文 | 定义 |
|------|------|------|
| iFay | iFay | 智能认知伙伴系统，技能共享协议的主要消费者，能够发现和调用技能以增强自身能力 |
| 技能 | Skill | 遵循协议声明的可调用能力单元，包括但不限于插件、API、知识包、任务执行能力 |
| 技能提供者 | Skill Provider | 在互联网上声明和暴露技能的实体（个人、组织或自动化系统） |
| 技能消费者 | Skill Consumer | 发现并调用技能的实体，主要为 iFay 实例 |
| 技能描述符 | Skill Descriptor | 遵循协议 Schema 定义的技能元数据文档，描述技能的能力、接口、调用方式等 |

## 2.2 协议术语

| 术语 | 英文 | 定义 |
|------|------|------|
| 发现机制 | Discovery Mechanism | 技能消费者在去中心化网络中定位和发现技能描述符的方法和流程 |
| 协议 Schema | Protocol Schema | 定义技能描述符结构的形式化规范，包含 JSON Schema、TypeScript 类型和 MDX 文档 |
| 技能注册表 | Skill Registry | 可选的技能索引服务，用于加速技能发现，但非协议运行的必要条件 |
| 调用端点 | Invocation Endpoint | 技能描述符中声明的远程调用入口地址 |
| 能力类型 | Capability Type | 技能的分类标识，包括 plugin、api、knowledge、task |
| Schema 验证器 | Schema Validator | 根据协议 Schema 验证技能描述符合规性的工具或组件 |
| 协议版本 | Protocol Version | 协议规范的版本标识，遵循语义化版本控制 |

## 2.3 技术术语

| 术语 | 英文 | 定义 |
|------|------|------|
| Well-Known URI | Well-Known URI | 标准化的发现路径 `/.well-known/skill-sharing`，用于暴露域名下的技能索引 |
| 技能索引 | Skill Index | Well-Known URI 返回的文档，包含域名下所有已声明技能的描述符引用列表 |
| 语义化版本控制 | Semantic Versioning (SemVer) | 版本号格式 `MAJOR.MINOR.PATCH`，用于协议版本管理 |
| JSON Schema | JSON Schema | 用于描述 JSON 数据结构的标准，本协议使用 Draft 2020-12 |
| 访问控制策略 | Access Policy | 技能的可见性级别：公开（public）、受限（restricted）、私有（private） |
| 执行 ID | Execution ID | 技能调用后返回的唯一标识符，用于追踪执行状态和获取结果 |
