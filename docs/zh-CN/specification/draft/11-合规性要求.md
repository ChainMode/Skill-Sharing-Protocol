# 11. 合规性要求

## 11.1 提供者合规性

声称兼容本协议 v1.0 的技能提供者 **MUST**：

1. 在 Well-Known URI 暴露有效的 Skill Index
2. 所有 Skill Descriptor 通过协议 Schema 验证
3. 实现描述符中声明的所有调用端点
4. 正确实现声明的认证类型
5. 遵循统一错误响应格式

## 11.2 消费者合规性

声称兼容本协议 v1.0 的技能消费者 **MUST**：

1. 在调用前对 Skill Descriptor 进行 Schema 验证
2. 实现版本兼容性检查
3. 处理协议定义的所有错误响应类别
4. 遵循认证流程

## 11.3 Schema 验证器合规性

声称兼容本协议 v1.0 的 Schema Validator **MUST**：

1. 实现第 10.4 节的所有要求
2. 验证结果正确：有效文档通过、无效文档失败
3. 序列化/解析具有往返一致性
