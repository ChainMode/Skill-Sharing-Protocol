# 1. 引言

## 1.1 协议概述

技能共享协议（Skill Sharing Protocol，以下简称"本协议"）定义了一套去中心化的机制，用于在互联网上**声明**、**发现**和**调用**技能（Skill）。任何遵循本协议的实体均可作为技能提供者或技能消费者参与协议运作，无需依赖任何中心化平台。

## 1.2 设计目标

本协议旨在实现以下设计目标：

1. **去中心化**：技能的声明和发现不依赖任何中心化注册表或平台
2. **自描述性**：每个技能通过标准化文档完整描述自身能力
3. **协议无关性**：协议本身仅规定数据结构与交互流程，不绑定具体实现技术
4. **可扩展性**：支持通过版本演进引入新能力而不破坏向后兼容
5. **安全性**：内建访问控制与认证机制

## 1.3 适用范围

本协议适用于：

- 任何希望以可被机器发现和调用的方式暴露能力的实体
- 任何需要发现和远程调用外部能力的智能体（特别是 iFay 实例）
- 任何基于本协议构建工具、SDK、注册表服务的开发者

## 1.4 关键词

本文档中的关键词 **MUST**（必须）、**MUST NOT**（禁止）、**SHOULD**（应当）、**SHOULD NOT**（不应）、**MAY**（可以）按照 [RFC 2119](https://www.rfc-editor.org/rfc/rfc2119) 的定义解释。
