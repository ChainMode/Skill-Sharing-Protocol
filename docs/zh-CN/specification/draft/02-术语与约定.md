# 2. 术语与约定

## 2.1 核心术语

| 术语 | 英文 | 定义 |
|------|------|------|
| 技能 | Skill | 遵循本协议声明的可调用能力单元 |
| 技能提供者 | Skill Provider | 在互联网上声明并暴露技能的实体 |
| 技能消费者 | Skill Consumer | 发现并调用技能的实体 |
| 技能描述符 | Skill Descriptor | 描述单个技能完整元数据的 JSON 文档 |
| 技能索引 | Skill Index | 列出某域名下所有可见技能描述符引用的 JSON 文档 |
| 协议版本 | Protocol Version | 本协议规范的版本标识，遵循 SemVer |

## 2.2 技术约定

- **数据格式**：本协议所有结构化数据 **MUST** 使用 JSON（[RFC 8259](https://www.rfc-editor.org/rfc/rfc8259)）
- **传输协议**：本协议所有网络交互 **MUST** 使用 HTTP/1.1 或更高版本
- **加密**：生产环境的所有通信 **MUST** 使用 TLS 1.2 或更高版本
- **字符编码**：所有文本 **MUST** 使用 UTF-8 编码
- **时间戳**：所有时间戳 **MUST** 使用 [ISO 8601](https://www.iso.org/iso-8601-date-and-time-format.html) 格式（如 `2025-10-25T08:00:00Z`）
- **版本号**：所有版本号 **MUST** 遵循 [Semantic Versioning 2.0.0](https://semver.org/)

## 2.3 命名约定

- **JSON 字段名**：**MUST** 使用 `snake_case`
- **枚举值**：**MUST** 使用 `lowercase_snake_case`
- **技能 ID**：**SHOULD** 使用反向域名加技能名称的形式（如 `com.example.translate-v1`）

## 2.4 记号约定

本规范使用 TypeScript `interface` 语法描述数据结构，仅作为简明记号，**不暗示实现必须使用 TypeScript**。所有结构的规范定义由 JSON Schema（`schema/{version}/schema.json`）给出，TypeScript 记号与 JSON 示例仅为辅助说明。
