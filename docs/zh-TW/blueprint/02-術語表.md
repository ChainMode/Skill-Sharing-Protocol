# 第二章：術語表

## 2.1 核心術語

| 術語 | 英文 | 定義 |
|------|------|------|
| iFay | iFay | 智慧認知夥伴系統，技能共享協定的主要消費者，能夠發現和呼叫技能以增強自身能力 |
| 技能 | Skill | 遵循協定宣告的可呼叫能力單元，包括但不限於外掛、API、知識包、任務執行能力 |
| 技能提供者 | Skill Provider | 在網際網路上宣告和暴露技能的實體（個人、組織或自動化系統） |
| 技能消費者 | Skill Consumer | 發現並呼叫技能的實體，主要為 iFay 實例 |
| 技能描述符 | Skill Descriptor | 遵循協定 Schema 定義的技能中繼資料文件，描述技能的能力、介面、呼叫方式等 |

## 2.2 協定術語

| 術語 | 英文 | 定義 |
|------|------|------|
| 發現機制 | Discovery Mechanism | 技能消費者在去中心化網路中定位和發現技能描述符的方法和流程 |
| 協定 Schema | Protocol Schema | 定義技能描述符結構的形式化規範，包含 JSON Schema、TypeScript 型別和 MDX 文件 |
| 技能註冊表 | Skill Registry | 可選的技能索引服務，用於加速技能發現，但非協定運行的必要條件 |
| 呼叫端點 | Invocation Endpoint | 技能描述符中宣告的遠端呼叫入口位址 |
| 能力類型 | Capability Type | 技能的分類標識，包括 plugin、api、knowledge、task |
| Schema 驗證器 | Schema Validator | 根據協定 Schema 驗證技能描述符合規性的工具或元件 |
| 協定版本 | Protocol Version | 協定規範的版本標識，遵循語意化版本控制 |

## 2.3 技術術語

| 術語 | 英文 | 定義 |
|------|------|------|
| Well-Known URI | Well-Known URI | 標準化的發現路徑 `/.well-known/skill-sharing`，用於暴露網域下的技能索引 |
| 技能索引 | Skill Index | Well-Known URI 回傳的文件，包含網域下所有已宣告技能的描述符參照列表 |
| 語意化版本控制 | Semantic Versioning (SemVer) | 版本號格式 `MAJOR.MINOR.PATCH`，用於協定版本管理 |
| JSON Schema | JSON Schema | 用於描述 JSON 資料結構的標準，本協定使用 Draft 2020-12 |
| 存取控制策略 | Access Policy | 技能的可見性層級：公開（public）、受限（restricted）、私有（private） |
| 執行 ID | Execution ID | 技能呼叫後回傳的唯一識別碼，用於追蹤執行狀態和取得結果 |
